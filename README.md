# 📦 PakEntpacker v1.0.6

A high-performance tool for extracting Enfusion engine `.pak` files, optimized for .NET 8.0.

### ✨ Key Features
* **Maximum Performance:** Multi-threaded processing using all available CPU cores.
* **Memory-Efficient:** Streaming decompression for stable extraction of massive archives.
* **Intelligent Workflow:** Automatically detects input files based on the execution context.

### 🚀 Usage Modes
* **Automatic:** Place the EXE in your game folder and run it to extract all local `.pak` files.
* **Drag & Drop:** Drop `.pak` files directly onto `PakEntpacker.exe` for instant extraction.
* **File Association:** Set as the default app to enable extraction via double-click.
* **Manual Selection:** If run in an empty folder, it automatically opens a Windows File Picker.

### 📋 Requirements
* Windows OS
* [.NET 8.0 Runtime](https://dotnet.microsoft.com/en-us/download/dotnet/8.0)
